# 給 C# 工程師的 Angular 系統化學習教材

從網頁基礎、TypeScript、Angular 22，到 API 串接、共用元件與 Docker 部署；並完整收錄七篇來源文章的技術細節與 .NET 類比。

- **整理與版本查核日期**：2026-10-31（基準版本：Angular 22 正式版 v22.2.4）
- **適用對象**：已學過 C# 的型別、類別、集合、例外與基本非同步語法，尚未完整開發過前端應用程式的工程師。
- **貫穿案例**：「產品管理後台」（顯示產品、搜尋、新增、修改、刪除、輸入驗證、失敗處理，以及容器化部署）。

> 💡 **C# 工程師這樣想**：全書透過你已經熟悉的 .NET / ASP.NET Core / WPF / Blazor 概念來對照，幫助快速建立直覺。
>
> 📌 **校正**：針對來源文章中容易造成誤解的說法，提供以官方文件為準的精準解釋。
